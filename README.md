# SOEN 6611 – iBank Project

## Overview

This repository contains the implementation and supporting deliverables for the **iBank Project** developed as part of **SOEN 6611 – Software Measurement** at Concordia University.

The objective of the project is to develop an **Automated Banking Machine (ABM)** application and produce a collection of software engineering artifacts for software measurement and quality evaluation throughout the project lifecycle. The project follows object-oriented design principles and incorporates software measurement techniques introduced in the course.

---

## Project Description

The iBank system simulates a modern Automated Banking Machine (ABM) designed for use in Canada. The application provides a graphical user interface (GUI) and supports common banking operations while emphasizing:

* Object-oriented software design
* Software quality measurement
* Maintainability
* Readability
* Reusability
* Security
* Usability
